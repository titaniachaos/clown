# Jede Art, wie dieser Arbeitsraum sich ablegen könnte

Das Archiv nebenan ist gebunden wie Queneaus Sonette: neunzehn Positionen,
Dutzende Fotografien für jede, und dreht man eine Zeile, bleiben die anderen
achtzehn stehen. Das trägt, weil die Positionen unabhängig sind — ein Bild an
einer Stelle zu verwenden nimmt es keiner anderen weg.

Hier sind sie es nicht, und darin liegt das Interesse. Dieser Arbeitsraum hält
elf Texte und stellt elf Fragen, und jeder Text trägt die Fragen, um die es ihm
wirklich geht. Eine Ablage gibt jeder Frage einen Text und verwendet jeden Text
genau einmal: eine vollständige Rechenschaft, in der nichts doppelt gesagt und
nichts ausgelassen wird. Es gibt 1482 davon.

## Warum eine Zeile eine andere bewegt

Nimm den Text, der *Alleinsein* beantwortet, und gib ihn *Publikum* — dann muss
etwas anderes zu *Alleinsein* kommen, denn jeder Text wird genau einmal
verwendet. In der Kombinatorik ist eine Ablage ein System distinkter
Repräsentanten; die Bedingung ist es, die aus einem Mischen eine Rechenschaft
macht.

Darum ist die Adresse auch eine schlichte Zahl und nicht die gemischt-radixe des
Archivs. Dort sind die meisten Zahlen Anordnungen, und die wenigen anderen kann
man zurückweisen. Hier gäbe dasselbe Verfahren 3.810.240 Zahlen, von denen 1482
Ablagen sind — eine von 2570 — und eine Adresse, die meist woanders landet, ist
keine. Also sind die Ablagen in fester Reihenfolge aufgezählt und von 0 bis 1481
nummeriert, und jede Zahl ist eine.

## Was es nicht ablegt

Das Verzeichnis. Jeder Eintrag dort bindet eine Wendung dieser Dokumentation an
das Werk, auf das sie sich stützt, mit einem Status, ob dieses Werk aus erster
Hand gelesen wurde. Eine Maschine, die das anders paarte, erfände Wissenschaft,
und die Belege existieren genau dafür, dies unmöglich zu machen. Hier wird das
Geschriebene abgelegt — es handelt von Themen, die es wirklich trägt — und die
Zitate bleiben, wo sie hingesetzt wurden.
